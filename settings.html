Settings

Shared across both trackers: exchange rates, the AI provider and key used to read payslips, and your data backup.

Exchange rates (→ EUR)

Everything is reported in EUR. Set a rate for each currency you enter figures in — payslips, and the "Amounts in" pickers on a tax year. There's no live rate feed; you set these. Changing a rate does not restate figures already stored in EUR — re-enter those in their own currency to convert them again.

AI provider Temporary — testing

Payslip analysis calls whichever provider is selected here. This is set up for a one-off quality comparison — Gemini is what ships at release. Switch back to Gemini any time by picking it below.

AI settings (Google Gemini)

⚠️ Your API key is saved only in this browser's local storage — it is never included in Export/Import backups, and requests go straight from your browser to Google (this site has no server of its own). Get a key at aistudio.google.com/apikey and treat it like a password.

AI settings (Anthropic Claude) Temporary — testing

⚠️ Your API key is saved only in this browser's local storage — it is never included in Export/Import backups, and requests go straight from your browser to Anthropic (this site has no server of its own). Get a key at console.anthropic.com/settings/keys — separate, pay-as-you-go API billing, not a claude.ai subscription — and treat it like a password.

Travel tracker

Upload your Travel Tracker report (.xlsx) and each tax year shows where you actually were — days of presence and days worked per country, which is what the day-count rules turn on. Only the totals are kept; the daily rows are not stored.

Data

Everything lives in this browser's local storage — clearing site data wipes it. Back it up as a JSON file, restore from one, or wipe everything and start over. API keys are never part of a backup.
